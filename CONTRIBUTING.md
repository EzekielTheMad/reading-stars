# Contributing

Small fixes, usability improvements, accessibility improvements, and self-hosting documentation are welcome. Open an issue describing the problem and expected behavior before a large change.

Use Node 24.14+, `npm ci`, `npm run build`, `npm test`, and `npm run check:public`. Use `npm run demo` for fictional data. Keep reader/parent checks on the server, preserve existing agreed rewards and quiz pins, and test changes to submission or award handling for duplicate requests.

Do not commit household data, `.env` files, credential values, deployment logs, screenshots of real children/profiles, commercial book jackets, or quiz banks without redistribution rights. A link to a publicly readable source is not permission to redistribute its contents. Include provenance and permission for contributed sample content; original demo material should be MIT-compatible.

By submitting a contribution, you agree to license your original contribution under this repository's MIT license. Dependencies and third-party material retain their own terms. Report security problems as described in SECURITY.md rather than including exploit details or private data in a public issue.
